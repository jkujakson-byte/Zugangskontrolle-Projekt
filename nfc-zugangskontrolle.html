Vorgehen

1

Bibliothek installieren

In der Arduino IDE unter "Werkzeuge → Bibliotheken verwalten" nach "MFRC522" suchen und die Bibliothek von GithubCommunity installieren. Sie übernimmt die komplette Kommunikation mit dem Modul.

2

Karten-ID auslesen

Zuerst das Beispiel-Sketch "DumpInfo" aus der Bibliothek hochladen und jede deiner Karten einmal an den Sensor halten. Im Seriellen Monitor erscheint die eindeutige UID jeder Karte — die brauchst du im nächsten Schritt.

3

Eigenen Code hochladen

Den Sketch unten verwenden und die UID deiner "bekannten" Karte im Code eintragen. Bei Erkennung öffnet der Servo, die grüne LED leuchtet. Bei unbekannten Karten bleibt die Schranke zu, die rote LED leuchtet.

4

Testen

Bekannte Karte an den Sensor halten → Servo öffnet. Eine andere, unregistrierte Karte testen → Servo bleibt geschlossen, rote LED leuchtet.

Der Code

Ersetze die Beispiel-UID unten durch die UID deiner eigenen Karte aus Schritt 2.

#include <SPI.h>
#include <MFRC522.h>
#include <Servo.h>

#define SS_PIN 10
#define RST_PIN 9

MFRC522 rfid(SS_PIN, RST_PIN);
Servo schranke;

// UID deiner eigenen Karte eintragen (aus Schritt 2)
byte bekannteUID[4] = {0x12, 0x34, 0x56, 0x78};

const int ledGruen = 5;
const int ledRot = 4;

void setup() {
  Serial.begin(9600);
  SPI.begin();
  rfid.PCD_Init();
  schranke.attach(6);
  schranke.write(0);  // Schranke zu
  pinMode(ledGruen, OUTPUT);
  pinMode(ledRot, OUTPUT);
}

void loop() {
  if (!rfid.PICC_IsNewCardPresent() || !rfid.PICC_ReadCardSerial()) {
    return;
  }

  bool bekannt = true;
  for (byte i = 0; i < 4; i++) {
    if (rfid.uid.uidByte[i] != bekannteUID[i]) {
      bekannt = false;
    }
  }

  if (bekannt) {
    Serial.println("Zugang erlaubt");
    digitalWrite(ledGruen, HIGH);
    schranke.write(90);  // Schranke auf
    delay(3000);
    schranke.write(0);
    digitalWrite(ledGruen, LOW);
  } else {
    Serial.println("Zugang verweigert");
    digitalWrite(ledRot, HIGH);
    delay(1000);
    digitalWrite(ledRot, LOW);
  }

  rfid.PICC_HaltA();
}

Häufige Probleme

  • Der Sensor erkennt gar keine Karte.

    Meist liegt es an der Stromversorgung — das RC522-Modul braucht 3,3V, nicht 5V. Mit 5V betrieben, funktioniert es oft gar nicht oder nur unzuverlässig.

  • Die UID ändert sich bei jedem Auslesen.

    Das deutet auf eine wackelige Verbindung hin — Breadboard-Kontakte und Kabel prüfen, besonders SDA und RST.

  • Der Servo zittert nur, statt sich zu drehen.

    Meist reicht der Strom vom Arduino-Pin nicht aus. Bei größeren Servos eine externe 5V-Stromquelle für den Servo verwenden, GND aber mit dem Arduino verbinden.
